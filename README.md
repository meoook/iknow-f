# iVanga

Frontend for iVanga app

# z-index

| index      | element                                               |
| ---------- | ----------------------------------------------------- |
| 0 or unset | Primary layout                                        |
| 1 or unset | Select                                                |
| 1 or unset | dropdown on surface (like report options for message) |
| 5          | header                                                |
| 5          | TapBar                                                |
| 6          | dropdown search                                       |
| 7          | dropdown user menu                                    |
| 8          | dropdown notifications                                |
| 9          | mobile menu                                           |
| 9          | BackToTop                                             |
| 10         | drawer                                                |
| 10 -> 11   | modal                                                 |
